# Local Gallery

ローカルフォルダにたまった生成物(画像・動画・音声・HTML レポート)をブラウザで閲覧できる、
読み取り専用の Web ギャラリーです。元のファイルはワンクリックでダウンロードできます。
Python 標準ライブラリだけで書かれた単一モジュールで、依存パッケージはありません。

[English](README.md) · [한국어](README.ko.md)

## 解決する課題

スクリプトやレンダラー、AI エージェントは、出力フォルダに次々と結果を書き込みます。
それをブラウザでサムネイル一覧・動画のインライン再生・原本のダウンロードボタン付きで
見たいけれど、メディアサーバーを別途導入したくはありません。かといって、ビューアが
ファイルを変更・削除したり、フォルダの外をのぞいたりできては困ります。

Local Gallery は役割を分けます。ファイルを作る側は書き込むだけ、ギャラリーは読んで
見せるだけです。

## 保護策

- **読み取り専用。** 実装しているのは `GET` だけです。`POST`/`PUT`/`DELETE` には `405`、
  それ以外のメソッドには `501` を返します。ファイルを書き込む・名前を変える・削除する
  コードは一切ありません。原本のダウンロードは「読み取り」なので対応しています。
- **登録したルートの外に出ない。** `..` セグメント、ドライブレターなど `:` を含む
  セグメント(NTFS 代替データストリームを含む)、未登録のパス、パーセントエンコードされた
  親ディレクトリ移動、ルートの外を指すシンボリックリンクやジャンクションはすべて拒否
  します。包含チェックは完全に解決(resolve)したパスで行います。安定したツリーが前提で、
  同時のファイル置換には安全ではありません(制限事項を参照)。
- **隠しファイル・秘密情報らしき項目は見えない。** ドットで始まるファイルや資格情報
  らしき名前(`.env`、`*.pem`、`*.key`、`id_rsa`、`token`・`secret`・`password`・
  `credential` を含む名前、`auth.json`、ブラウザの `Cookies`/`Login Data`、`id_ed25519`、
  `id_ecdsa`、`.ppk`、`.kdbx`、`.jks`、`wallet.dat`、`.ssh`・`.aws`・`AppData` などのフォルダ)は
  一覧に出ず、直接要求しても
  取得できません。Windows の 8.3 短縮名(`ENV~1`)や、ルート内の無害そうな名前の
  シンボリックリンクといった別名でも回避できません。
- **プラットフォームの MIME 推測ではなく固定のインライン許可リスト。** `_INLINE_TYPES` の
  ラスター画像・動画・音声・`.txt` 拡張子のみ、固定 MIME でインライン送信します。
  SVG/HTML/XML、`.xht`、`.rdf`、`.xsd`、`.wsdl`、未知の拡張子など、それ以外はすべて
  `application/octet-stream` + 添付 + `Content-Security-Policy: default-src 'none'; sandbox`
  で送ります。全ファイル応答に `X-Content-Type-Options: nosniff` を付けます。これは応答方針で
  あってブラウザの脆弱性がないという保証ではありません。添付方針により SVG サムネイルが
  表示されない場合があります。
- **どんなファイル名でもダウンロードできる。** `Content-Disposition` は RFC 6266 /
  RFC 5987 に従い、ASCII の代替名と、`filename*` に入れた UTF-8 の正確な名前を送ります。
  韓国語・日本語・絵文字の名前もそのまま保存でき、名前に含まれる引用符や改行(CR/LF)で
  ヘッダーを差し込むこともできません。
- **既定ではローカル限定。** 指定しない限り `127.0.0.1` にだけバインドします。
- **認証より先に Host を検査。** 設定したバインド名/アドレスと実際のポートのみ受け付けます
  (ローカルバインドでは `localhost`/`127.0.0.1` も許可)。欠落・重複・信頼しない `Host` は
  `421` です。ワイルドカードバインドでも任意の LAN ホスト名は許可しません。リバース
  プロキシはポート込みの許可されたローカル Host を転送する必要があります。
- **非ループバックにはトークン必須。** 未設定なら CLI/API がバインド前に拒否します。
  トークンなしでバインドできるのはループバック IP リテラルと `localhost` だけです。
- **任意のアクセストークン**と HttpOnly セッション Cookie(後述)。

## 設計

モジュールは `local_gallery/gallery.py` ひとつです。判断はすべて純粋関数が担い、薄い
`http.server` ハンドラーがそれを呼び出します。

| 関数 | 役割 |
| --- | --- |
| `parse_roots(spec, default_root, default_name)` | `名前=パス;名前=パス` → `{名前: 解決済みフォルダ}`、なければ既定フォルダひとつ |
| `is_hidden(name)` | ドットファイル、秘密情報らしき名前、保護フォルダの判定 |
| `safe_resolve(roots, rel)` | `ルート/サブ/パス` → `(ルート, 絶対パス)` または `None` |
| `list_dir(path)` | 隠し項目を除いたフォルダ一覧(フォルダ優先、最大 2000 件) |
| `classify_ext(name)` | 表示用の種別 `image` / `video` / `audio` / `other` |
| `content_disposition(filename)` | RFC 5987 形式の添付ヘッダー値 |
| `render_roots_page`, `render_dir_page` | HTML ページ(名前はすべてエスケープ、リンクはすべてパーセントエンコード) |
| `serve(roots, host=, port=, token=)` | Ctrl+C までサーバーを実行 |
| `main(argv)` | `local-gallery` コマンド |

`safe_resolve` は次の順に検査します。未登録のルート名 → `..`・`.`・`:` のセグメント →
隠しセグメント → `Path.resolve()` の結果がルート内か → 解決後のパスに隠し名がないか。
純粋関数なので、テストでは直接呼び出したうえで HTTP 経由でも確認しています。

サムネイルはブラウザが原本を縮小表示する方式(`<img loading="lazy">`)で、サーバー側の
サムネイルキャッシュやトランスコードはありません。ファイルは 64 KiB 単位でストリーミング
します。

**トークンの流れ。** `LOCAL_GALLERY_TOKEN` を設定したら、まず `/?token=<値>` を開きます。
成功したページ/ファイル応答が `local_gallery=<ランダムなセッション ID>; Path=/; HttpOnly;
SameSite=Strict; Max-Age=3600` を発行します。再利用可能なログイントークンそのものは
Cookie に入りません。セッションはサーバーメモリにのみ保存し、そのサーバーだけで絶対
1 時間有効です(閲覧しても延長されません)。最大 1024 件で、超過時は最古のものから
削除します。再起動で全件無効です。リンクにログイントークンは入りません。有効なセッション
またはクエリトークンがなければ `401`、ログイントークンの比較は定数時間です。
全応答に `Cache-Control: no-store` と `Referrer-Policy: no-referrer` を付けます。

## クイックスタート

```bash
pip install .                 # 開発時: pip install -e ".[test]"

cd path/to/outputs
local-gallery                 # カレントフォルダを http://127.0.0.1:18140 で公開

# 複数フォルダ、名前の指定、別のポート
local-gallery --root renders=./renders --root /srv/reports --port 8080

python -m local_gallery --help
```

表示された URL を開くとフォルダのカードが並び、中に入ると画像サムネイル、動画・音声
プレーヤー、原本をダウンロードする ⬇ ボタンのグリッドが表示されます。

| 設定 | CLI | 環境変数 | 既定値 |
| --- | --- | --- | --- |
| フォルダ | `--root [名前=]パス`(複数指定可) | `LOCAL_GALLERY_ROOTS="名前=パス;名前=パス"` | カレントフォルダ |
| バインドアドレス | `--host` | `LOCAL_GALLERY_HOST` | `127.0.0.1` |
| ポート | `--port` | `LOCAL_GALLERY_PORT` | `18140` |
| アクセストークン | — | `LOCAL_GALLERY_TOKEN` | なし(localhost で公開) |

`--root` は `LOCAL_GALLERY_ROOTS` より優先されます。`名前=` を付けないルートはフォルダ名が
そのまま名前になり、名前が重複すると起動を拒否します。

`LOCAL_GALLERY_ROOTS` が**未設定のときだけ**カレントフォルダにフォールバックします。
明示した値が空・不正・存在しないパスで有効なフォルダがゼロなら、サーバー開始前に失敗します。
`parse_roots` API は互換性のため、個々の無効項目を無視し有効項目は維持します。
暗黙のホーム/ドライブルートは拒否します。意図的に公開するには `--root` が必要です。
別のカレントフォルダにも個人ファイルがあり得るため、専用の出力フォルダを推奨します。

### アクセストークン

CLI はコマンドライン引数ではなく環境変数からトークンを読むので、プロセス引数には
残りません。秘密のリテラル値をシェル履歴に直接入力しないでください。URL で安全に使える
ランダムな ASCII 値を使ってください。

```bash
export LOCAL_GALLERY_TOKEN="$(python -c 'import secrets; print(secrets.token_urlsafe(24))')"
local-gallery
# http://127.0.0.1:18140/?token=<同じ値> を一度開けば、以降は Cookie で維持される
```

PowerShell: `$env:LOCAL_GALLERY_TOKEN = python -c "import secrets; print(secrets.token_urlsafe(24))"`

既定で同梱・自動生成されるトークンはありません。トークンはあくまで第二の防御線で、
ネットワークのアクセス制御の代わりにはなりません。TLS はなく、最初の URL には一度だけ
トークンが含まれます。

### HTTP エンドポイント

| リクエスト | 結果 |
| --- | --- |
| `GET /` | ルートごとにカードひとつ |
| `GET /view?path=ルート/サブ/フォルダ` | フォルダのグリッド |
| `GET /raw?path=ルート/サブ/ファイル` | 固定許可リストのみインライン、その他はすべて添付 |
| `GET /raw?path=ルート/サブ/ファイル&download=1` | 添付ファイルとしてダウンロード |

拒否時のコード: `401` トークンが必要、`403` パス規則違反、`404` 存在しない、`405` 書き込み
メソッド、`421` 信頼しない Host。

## テストの実行

```bash
python -m venv .venv
. .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -e ".[test]"
pytest -q
```

一部のテストは、OS が前提条件を用意できない場合にスキップされます。シンボリックリンク
(開発者モードや管理者権限のない Windows。フォルダリンクのテストはその場合 NTFS
ジャンクションで代わりに検査)と、Windows の 8.3 短縮名(ボリュームで有効な場合のみ)です。

### サンプル

```bash
python examples/demo.py          # 合成フォルダ + 実サーバーで、応答内容を表示
python examples/demo.py --keep   # 同じ処理のあと、サーバーを起動したままにして閲覧できる
```

デモは一時フォルダに PNG グラデーション、韓国語名の HTML レポート、メモ、`.xht` 添付、
合成の隠し `.env`/`auth.json` を作ります。一覧/ダウンロードリンク、原本バイト、RFC 5987
ヘッダー、添付方針と拒否要求(`../`、`%2e%2e`、`.env`、`auth.json`、`POST`)を assert で検査して
表示します。一致しなければ非ゼロの終了コードになります。

## 制限事項と対象外

- アップロード・削除・名前変更・編集はありません。意図した設計です。
- TLS もユーザーアカウントもありません。`127.0.0.1` で使い、リモートから使う場合は公開
  インターフェースに直接バインドせず、VPN や認証付きリバースプロキシを使ってください。
- Cookie は**ポートで分離されません**。同じホストの別サービスが有効なセッション ID を受け取り、
  期限まで発行元ギャラリーに再送できます。HttpOnly/SameSite では防げません。ログイントークン
  原文は露出しなくなりましたが、セッション窃取の危険は残ります。信頼しないサービスと共有
  しない専用のギャラリーホスト名を使い、許可するバインド/転送 Host を設定してください。
  ポートが違うギャラリー同士で Cookie を上書きすることもあります。この HTTP サーバーは
  Secure 属性を付けません。最初のトークン URL は履歴に残り得て、応答ヘッダーはそれを
  消しません。個別ログアウト用エンドポイントはなく、再起動または期限で無効にします。
- サーバー側のサムネイル、トランスコード、ページ分割はありません。大きな画像が多い
  フォルダはブラウザに負荷がかかり、一覧はフォルダごとに 2000 件で打ち切られます。
- `HEAD` と HTTP `Range` に対応していないため、長い動画のシークが制限されたり、
  ブラウザによっては動画のストリーミングを拒否したりする場合があります。
- 隠しファイルのフィルターは中身ではなく名前で判定します。普通の名前の秘密ファイルを
  含むフォルダをルートにしないでください。
- **ファイルシステムの競合は未解決です。** 検証/`stat`/`open` は別々のパス操作であり、ルートを
  基準とする安全なハンドル走査ではありません。同時にファイル・シンボリックリンク・
  ジャンクションを置換されると、読む対象の変化、検査したツリーからの逸脱、応答サイズの
  不整合が起こり得ます。書き手を止めるか運用側で読み取り専用にした、信頼できる安定した
  コピーを公開してください。ギャラリー自身はスナップショットを作らず、この条件を強制しません。
  安定したリンクのテストは競合安全性の証明ではありません。攻撃者が書けるツリーは公開しないでください。
- ルートの外を指すシンボリックリンクが(リンク先のサイズとともに)一覧に表示される
  ことがありますが、開こうとすると拒否されます。

## 由来

Local Gallery は、個人用 AI アシスタントプロジェクト willind の一部として開発され、
アシスタントが生成した画像・動画・レポートを表示するために使われていました。この
リポジトリはその機能を独立させたもので、プロジェクト固有のパスや名前をオプションに
置き換え、テストを合成データに移しています。
